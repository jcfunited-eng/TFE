# Curriculum

Two curricula exist: the session's (how you learn the project) and the
system's (how the physics learns the market). Both are strictly
cumulative and causal; neither ever has a train/test split.

## Session curriculum (read in this order after context loss)
1. Memory index (auto-loaded) — hard rules and condemned ideas first.
2. docs/CH4_LIVE_TIMING_AUDIT_20260731.md — the reveal-bar theorem
   and every addendum; this is the project's current epistemic state.
3. docs/CH4_SCHEMA_MEMORY_WAYPOINT_20260730.md — the established law,
   the harvest ladder history, the falsified list.
4. docs/CH4_HERD_KGATE_V1_BUILD_PLAN.md + tools/ch4_herd_kgate_live.py
   — what is actually live and why.
5. The merged spec (UF-Spec v1.3 lineage) BEFORE proposing any kernel
   change — spec-grounded answers only, no recycled diagnosis.
The falsification ledger IS the curriculum: what failed teaches more
than what worked. Never rebuild a falsified idea (tfe-condemned-ideas).

## System curriculum (how the machinery learns)
- **There is no training.** "There are no such thing as training years
  there is only geometric structure over an evaluation period" (Joe).
  Any design with fit/holdout phases is condemned quant framing.
- The schema memory accumulates species completions in strict global
  causal order; every prediction uses only what was revealed before
  its own issue instant. Learning = the record fattening, never
  parameters fitting.
- New knowledge enters ONLY through real mechanisms: more history
  (store extension), finer rungs, new completion objects, new
  conditioning frames (herd/pedigree) — each tested against the
  binomial null and across independent rungs before belief.
- Constants are declared, derived, or pinned by the spec — never
  tuned to outcomes.

## Curriculum debt (open lessons not yet earned)

richer pedigree axes than liquidity rank; completion objects beyond
displacement sign. Extend the ladder there, not by re-walking rungs.
