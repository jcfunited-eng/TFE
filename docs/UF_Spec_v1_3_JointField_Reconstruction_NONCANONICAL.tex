CONSTITUTION (operative laws for TFE joint-field shadow work):
1. The full explicit field is authoritative. A score, bucket, cell
   key, compatibility vector, or selected pivot is never a substitute.
2. All operators deterministic. No ML, no fitted parameter, no
   stochastic surrogate.
3. Every output causally supported by a finite input interval.
4. Missing / invalid / unavailable / observed-quiescent are DIFFERENT
   states; never replaced by zero.
5. No scalar authority: a scalar summary cannot authorize a field
   relation or decision; displayed scalars are reduced diagnostics
   that must disclose their lost atoms.
6. Gates: maximal contiguous intervals of unchanged exact sign/zero
   structural signature — NO fitted threshold.
7. TVR is the full component tensor (T, {V_v}, {R_v}, {Q_v^(s)},
   {K_v}) — never a three-scalar fingerprint.
8. Contradiction atoms (cross-scale, cross-perspective sign
   disagreements) are retained explicitly, never averaged away.
9. L4 = seven typed fields (D, M, R_rev, U*, C, P, B) as exact
   atom-wise recursions on sign facts.
10. Validation: label-blind complete matrices; labels revealed only
    after all relations exist; source-disjoint held-out; exact
    invariants at 100%; empirical floor 85% never relabelled exact.
11. Shadow runs beside canonical; both filed; no automatic winner;
    the reconstruction never routes into production.
