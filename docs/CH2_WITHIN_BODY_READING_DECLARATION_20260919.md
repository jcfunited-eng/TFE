# The nine-field reading in the structure's own frame — declaration (2026-09-19)

Declared BEFORE any result.

## What was wrong with the previous test, in Joseph's words

"It is not a day picking too."

`CH2_NINE_FIELD_READING_DECLARATION_20260919.md` measured the reading as a
daily cross-sectional contest: of every name eligible on a calendar day, do the
ones the reading marks outrun the ones it does not. **The kernel never runs
that contest.** It follows one structure through its own life. A calendar day
is a slice I imposed; so is a 30- or 60-session hold.

Both are the financial reframing that keeps getting reintroduced. This
measurement removes both.

## What changes

**1. The unit is a body's life, not a day.** Every name is its own control.
The question is whether the reading marks the moments in *this structure's*
life that precede its rises — never whether it beats other structures on a
calendar date.

**2. The field closes the position, not a calendar.** The entry is authorized
by a state. The position is held until that state ends, and the state's end is
read at native levels exactly as the entry was. First of these, on any closed
session after entry:

- **`R_rev_k = 1`** — a major geometry break. Joseph: a first-class change in
  state. It ends the state that authorized the entry.
- **`B_k = −1`** — carry exhausted. The stored potential is spent.
- **`S_UF ≤ U_star_k` and `R_UF ≤ U_star_k`** — both support and resonance have
  fallen under the uncertainty penalty. The field is no longer trustworthy.
  Either one alone does not close: `U_star_k` is read against both.
- **`D_k = −1`** — direction turned negative. Not `D_k = 0`: Joseph's three
  values are positive, neutral, negative, and neutral is not a reversal.

No stop, no target, no time limit, no trailing anything. If none of the four
ever fires, the position runs to the end of the data and is counted there.

**3. One position per structure at a time.** Entries are non-overlapping: after
an entry, the next is taken no earlier than the session following its exit.
Otherwise one rise is counted dozens of times.

## Population

`bar_count ≥ 250`; median dollar volume over 20 sessions ≥ $5 M (mine, on
trial, so an order can fill). No price floor.

## The null — random timing inside the same body, matched length

For every real position in a name, a position in **that same name** starting at
a uniformly random session of its life and held for the **same number of
sessions** as the real one. Same name, same count, same durations — only the
timing differs. **200 seeds.**

This is the only null that answers the question asked. A cross-sectional null
is not used and its absence is deliberate.

## The bar

The reading's mean return per position must exceed the 95th percentile of the
matched-timing null, and must do so in **both halves** (split 2024-03-15) of
the entry dates. Anything less is reported as measured.

## Reported alongside, not selected on

  which nothing in this measurement sets.
- Which of the four state-ends closed each position, and the return by exit
  cause.
- The reading's outcome graded by `P_k` and `C_k`, as before.
- The same figures in each tercile of dollar volume, for the `epsilon_D`
