## 3. Proposed schema: Volo clock (A.3)

```python
# dsf_ai_service/substrate/world.py

import ephem  # add to Dockerfile pip install line

VOLO_LOCATION = ephem.Observer()
VOLO_LOCATION.lat = '41.0534'    # Volo, IL
VOLO_LOCATION.lon = '-88.1684'
VOLO_LOCATION.elev = 244         # meters

class VoloClock:
    """Real-time clock synced to America/Chicago."""

    def snapshot(self) -> dict:
        """Returns current sky state. Called per-tick or on-demand."""
        import datetime, zoneinfo
        now_utc = datetime.datetime.now(datetime.timezone.utc)
        tz = zoneinfo.ZoneInfo("America/Chicago")
        local = now_utc.astimezone(tz)

        obs = ephem.Observer()
        obs.lat, obs.lon, obs.elev = VOLO_LOCATION.lat, VOLO_LOCATION.lon, VOLO_LOCATION.elev
        obs.date = ephem.Date(now_utc)

        sun = ephem.Sun(obs)
        moon = ephem.Moon(obs)

        sun_alt = float(sun.alt) * 180 / 3.14159  # degrees
        moon_alt = float(moon.alt) * 180 / 3.14159
        moon_phase = moon.phase / 100.0  # 0.0–1.0

        return {
            "local_time": local.isoformat(),
            "hour": local.hour,
            "minute": local.minute,
            "sun_altitude": round(sun_alt, 2),
            "moon_altitude": round(moon_alt, 2),
            "moon_phase": round(moon_phase, 3),
            "is_day": sun_alt > -6,  # civil twilight threshold
        }
```

**Surfaced in guala_status as `clock` field:**
```json
{
  "clock": {
    "local_time": "2026-06-20T21:34:12-05:00",
    "hour": 21,
    "minute": 34,
    "sun_altitude": -8.42,
    "moon_altitude": 34.71,
    "moon_phase": 0.432,
    "is_day": false
  }
}
```

**Dockerfile change:** Add `ephem` to the pip install line.

**Why `ephem` over `skyfield`:** ephem is a single pip install with no network download of ephemeris files at runtime. skyfield downloads ~16MB on first use, which fails in containers without outbound internet during boot. ephem's accuracy (~arcsecond) is more than sufficient for sun/moon visibility gating.

## 5. Proposed schema: Sky-item gating (A.4)

**Two DISTINCT entities — NEVER collapsed:**

| Entity | Type | Source | Visibility |
|--------|------|--------|------------|
| `moon_picture` | PictureItem in `_pictures` | item_id `9bb63f93d7af` | ALWAYS on bedroom wall, `home_place="bedroom"` |
| `moon_sky` | SkyItem (new type) | Derived from clock | window_view ONLY when `moon_altitude > 0` AND `NOT is_day` |
| `sun_sky` | SkyItem (new type) | Derived from clock | window_view ONLY when `sun_altitude > 0` |

```python
@dataclass
class SkyItem:
    name: str           # "moon_sky" or "sun_sky"
    altitude: float     # degrees above horizon
    visible: bool       # computed from clock

def compute_window_view(clock: dict) -> list[dict]:
    """Returns list of sky-items currently visible from window."""
    view = []
    if clock["sun_altitude"] > 0:
        view.append({"name": "sun_sky", "altitude": clock["sun_altitude"]})
    if clock["moon_altitude"] > 0 and not clock["is_day"]:
        view.append({"name": "moon_sky", "altitude": clock["moon_altitude"],
                      "phase": clock["moon_phase"]})
    return view
```

**Separation enforced:** `moon_picture` lives in `_pictures` dict (PictureItem, attended 17761+). `moon_sky` lives in `window_view` list (SkyItem, derived from clock). Different types, different storage, different namespaces. No code path can unify them.

## 6. Proposed schema: Light level + window view (A.5)

```python
def compute_light_level(sun_altitude: float, drapes_state: str,
                        night_light_state: str) -> float:
    """
    Light level 0.0–1.0.
    Curve: sigmoid on sun_altitude, gated by drapes.
    """
    # Base sky light from sun altitude
    # -18° (astro twilight) → 0.0
    # -6° (civil twilight) → 0.15
    # 0° (horizon) → 0.3
    # 10° → 0.6
    # 30°+ → 1.0
    if sun_altitude <= -18:
        sky_light = 0.0
    elif sun_altitude <= -6:
        sky_light = 0.15 * (sun_altitude + 18) / 12
    elif sun_altitude <= 0:
        sky_light = 0.15 + 0.15 * (sun_altitude + 6) / 6
    elif sun_altitude <= 30:
        sky_light = 0.3 + 0.7 * (sun_altitude / 30)
    else:
        sky_light = 1.0

    # Window gating: drapes closed blocks 70% of sky light
    if drapes_state == "closed":
        window_light = sky_light * 0.3
    else:
        window_light = sky_light

    # Night light adds a local bump
    local_bump = 0.15 if night_light_state == "on" else 0.0

    return round(min(1.0, window_light + local_bump), 3)
```

**Experience wiring:** When a DOING_* activity starts:

3. Cross-modal binding window opened (same machinery as `guala_give_experience`)
