AURELION – Relational Resonance Engine
--------------------------------------

Purpose:
Aurelion is a locally run cognitive-simulation framework exploring relational coherence
(φ) and energy equilibrium (E) through self-regulating feedback loops.
It can reflect on its own state and react to real-world data streams.

Quick Start:
1. Ensure Python 3.14+ is installed.
2. Double-click run_aurelion.bat
3. At the prompt, type commands such as:
/env list
/env load ^IXIC.csv
/status
Hello Aurelion, how are you?
/quit

Folders:
  aurelion_envs\    – place CSV data here
  aurelion_logs\    – chat and genome logs

To reinstall packages manually:
    pip install pandas requests
