**Lesson Plan: Introduction to Algebra**

**Objective:**  
Students will understand the basic concepts of algebra, including variables, expressions, and simple equations.

---

### Lesson Outline

**1. Gentle Explanation of Algebra (10 minutes)**  
Algebra is a branch of mathematics that uses letters and symbols to represent numbers and quantities in formulas and equations. Instead of just using numbers, we use "variables"—these are letters that stand for unknown values. For example, in the expression "x + 2," "x" is a variable that can be any number. Algebra helps us solve problems and find unknown values in different situations.

---

**2. Understanding Variables (15 minutes)**  
- **What is a Variable?**  
  A variable is a symbol, usually a letter like x or y, that represents a number we don't know yet.  
  **Example:** In the equation "x + 3 = 5," we want to find out what x is.

- **Why Use Variables?**  
  Using variables helps us create general rules or formulas that can be applied in various situations.

---

**3. Algebraic Expressions (15 minutes)**  
- **What is an Expression?**  
  An expression is a combination of numbers, variables, and operations (like addition, subtraction, multiplication, and division).  
  **Example:** The expression "2x + 4" means "2 times x plus 4."

- **Evaluating Expressions**  
  To evaluate an expression means to calculate its value by replacing the variable with a specific number.  
  **Example:** If x = 3, then 2x + 4 becomes 2(3) + 4 = 6 + 4 = 10.

---

**4. Simple Algebraic Equations (15 minutes)**  
- **What is an Equation?**  
  An equation shows two things are equal, using the equal sign (=).  
  **Example:** In the equation "x + 2 = 6," we are trying to find out what x is.

- **Solving Simple Equations**  
  To solve an equation, we need to find the value of the variable that makes the equation true.  
  **Example:** For x + 2 = 6, subtract 2 from both sides: x = 6 - 2, so x = 4.

---

### Exercises (10 minutes)

**Exercise 1:**  
Identify the variable in the expression "7y + 5."  
*Answer:* The variable is **y**.

**Exercise 2:**  
Evaluate the expression "3x + 2" when x = 4.  
*Answer:* 3(4) + 2 = 12 + 2 = **14**.

**Exercise 3:**  
Solve the equation "x - 3 = 7."  
*Answer:* Add 3 to both sides: x = 7 + 3, so x = **10**.

---

### Conclusion (5 minutes)  
Algebra introduces us to a new way of thinking about numbers and relationships. By using variables, expressions, and equations, we can solve many kinds of problems. Remember to practice regularly to become more comfortable with these concepts!
