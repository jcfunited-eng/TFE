# External vocal imitation falsification — 2026-07-27

Status: falsified; this path is not external word imitation.

The current
`Guala._attempt_lived_thing_vocal_learning` admits one recurrent external
auditory occurrence and one recurrent self-babble occurrence, then binds the
next program returned by `claim_next_babble_program()`. It never proves an
exact structural relation between the heard occurrence and the selected
larynx/tract program.

One controlled probe replayed the exact pressure generated by the first
unlabelled articulatory program from a nearby W1 companion:

- external mono firing: 95 recurrent neurons;
- the source program heard through self transduction: 39 neurons, all 39
  contained in the external firing set;
- the other articulatory program: 84 neurons, with 43 contained in the
  external firing set.

Thus presence of recurrence is insufficient, and overlap would select the
wrong candidate in this probe. No overlap score or tolerance has been added.
At the default companion distance, the same seed pressure produced zero
auditory occurrences, so that range/output problem also remains open.

The production-safe result implemented beside this record is narrower:
`test_engine_self_vocal_sight_recall.py` proves sight-only recall of a
self-generated vocal act learned in one simultaneous sight/sound/touch/body
THING occurrence. Its durable motor authority is the bounded larynx/tract
program and binding receipt; retained raw waveform bytes are zero. Every
recall synthesizes new pressure, and W1 rejects pressure changed after the
synthesis receipt was issued. It does not claim external imitation, a learned
letter, or word recognition.

The invalid babble cursor and overlap mechanisms must not be extended.
