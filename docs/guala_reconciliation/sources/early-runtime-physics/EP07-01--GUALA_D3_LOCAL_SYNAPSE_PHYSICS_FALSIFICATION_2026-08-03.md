## Surviving law

A named terminal retains only whether one local transmitter release is
available. An already-routed nonzero source winding may spend that availability
to produce one arrival at the terminal's exact mounted target. The arrival
retains the causal source winding so downstream physical law can respond to the
event, but it does not contain a target phase displacement.

A later addressed fluid/body recovery can restore one release. Repeated recovery
saturates rather than accumulating an unbounded count. Fan-out is not free:
each reached terminal spends its own local supply.

## Rejected law

The removed candidate calculated:

```text
(target phase node - source phase node) mod 3 -> target phase sign
```

ArcLoom establishes three-node winding geometry inside a Krimelack. It does not
establish that a synapse's endpoint-node difference alone determines the
receiving neuron's displacement. Receptor kind, receiving compartment, local
ion-driving state, and chemical species can materially change the effect.
Keeping that equation would therefore have converted locality into an invented
polarity table.
