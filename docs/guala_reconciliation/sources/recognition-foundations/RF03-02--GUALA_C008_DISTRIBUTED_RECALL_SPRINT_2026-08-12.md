## Falsified hypotheses and failures retained against rediscovery

- C-007's 217-neuron whole-sensorium component proves distributed recognition,
  not partial-cue recall or sparse attention.
- Static layer-9 contacts and a formation receipt prove topology/custody, not
  current reconstruction.
- The retired hippocampal archive and navigator are not recall and remain
  prohibited.
- Carrying every changed neuron or both endpoints of every active bond was
  previously falsified: it expanded `17 -> 81 -> 184 -> 222` transitioned
  neurons by promoting resting/local activity into a graph flood.
- Live task-995 trace at source tick `55,631`: the exact vestibular cue/return
  alternated `17` transitioned neurons over `25` bonds with `43` transitioned
  neurons over `76` bonds. Every return reassembled the exact 27-member
  formation, but active endpoints contained no layer 7 or layer 11. Repeating
  six intervals reproduced the same two-step loop rather than continuing the
  reconstructed state. The disposable successor was not published.
- An initial AWS JMESPath query used `starts_with` before excluding a null
  environment-name value. The corrected read-only query filters string names
  before prefix matching; this was command-shape evidence, not organism state.
- The first exact candidate wheel cold-restored task 995 but refused its first
  cue as noncanonical. The carrier-receiver frontier law was correct, while
  the V19 lineage validator still admitted only the predecessor's layer-9
  frontier. This is the originating evidence for RF-022; the codec framing and
  stored bytes do not change because existing task-995 frontiers remain valid.
- An intermediate implementation zipped carrier transitions to compact contact
  anatomy and treated its coordinate indices as neuron lineages. That boundary
  was false: `StablePhysicalBondReference` owns the lineage endpoints, while
  contact anatomy owns coordinate endpoints. The implementation now derives
  receiving lineages only from the bond reference paired with each exact
  signed carrier transition.
