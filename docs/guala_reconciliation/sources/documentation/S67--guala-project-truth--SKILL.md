   packaging, or benchmarks. Require the reviewer to classify each finding as
   either `localized` or `architectural`.
5. Classify as `architectural` any duplicated or split physical settlement,
   incomplete causal frontier, mutation before all fallible preparation,

   reachable predecessor mechanism, unbounded or population-wide hot work, or
   missing rollback/crash/restore branch. One architectural finding rejects the
   candidate as a design, regardless of how easily an individual line could be
   patched.
6. On architectural rejection, stop every owner, preserve the rejected diff as
   evidence, restore the executable tree to its accepted baseline, record the
   rejection, and return to the contract. Never repair a list of architectural

8. Compile and test only after a frozen source review passes. Run focused
