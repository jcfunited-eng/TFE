# Whole-organism cognitive mechanism catalog

This catalog prevents the historical fifteen gauges from being mistaken for the complete brain. It maps repository-defined cognitive responsibilities into the current one-neuron/recursive-formation architecture. It does not declare them implemented.

## Governing rules

1. All mechanisms co-develop in one organism and one causal transition. They are not independent owners, services, databases, hemispheres, or plug-ins.
2. The DSF tuple is one internal structural-delivery element of each reached neuron. It is not the neuron or a cognitive mechanism by itself.
3. Cognitive specialization arises from physical anatomy, topology, DNA expression, receptors/effectors, local state, sparse coupling, body/fluid conditions, and experience.
4. A mechanism name denotes a physical responsibility and evidence requirement, not a class name or UI row.
5. Use the ten non-flattened cognitive-capital dimensions for every mechanism: availability, participation, retention, recognition, recall, causal use, transfer, autonomous use, durability, and integration depth.
