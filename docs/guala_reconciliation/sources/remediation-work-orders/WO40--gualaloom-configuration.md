`/api/v1/gualaloom/events?n=50`, and GET `/api/v1/gualaloom/chi_density`.

```

displayed arousal   = min(1, dsf_delivery_count / 10 + (motion_present ? 0.3 : 0))
```

not the full DSF/global stability law. It loses the actual UF geometry and
joint-field relationships entirely. Do not publish this working page as a
truthful replacement for the old public one.
