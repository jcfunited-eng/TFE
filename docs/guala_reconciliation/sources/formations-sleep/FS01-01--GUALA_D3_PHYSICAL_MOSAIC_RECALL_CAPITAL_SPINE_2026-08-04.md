## Correct physical distinction

The first retained memory boundary and later recognition boundary are not the
same event:

```text
original experience
  -> complete-neuron cohort settlement
  -> exact post-experience quiescence
  -> one nonzero sparse retained fractal per changed neuron

later proper partial cue
  -> bounded active cohort recurrence
  -> sparse electrical propagation through learned physical state
  -> changed current frontier relative to the unlearned control
```

The original neuronal fractal requires post-experience quiescence. Recognition
and recall are active recurrence and do not require that later activity to be
misrepresented as a second completed memory. If the later activity eventually
reaches a new post-experience quiescence, a new fractal may then be evaluated
separately.
