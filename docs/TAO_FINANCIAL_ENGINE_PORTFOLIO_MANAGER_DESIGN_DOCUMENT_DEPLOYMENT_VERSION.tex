\section{Empirical Foundation}

The deployment design is grounded in \textbf{one measured result}. All constants and sizing in §§4--7 reference this measurement.

\subsection*{Cohort C1 Result (the deployment justification)}
\begin{itemize}
  \item $N = 372$ signals over 5 years on 2,194-ticker production-equivalent universe
  \item $\text{WR}_{20d} = \mathbf{91.9\%}$ (20 daily-bars forward return method, cleanest reference)
  \item Wilson 95\% CI: $\mathbf{[88.7\%,\; 94.3\%]}$
  \item Measurement period: 2021-04-01 to 2026-03-24
  \item Method stability: 91.9\%--92.2\% across three independent methods\\
        (20 gate-events / 20 SPY-calendar trading days / 20 daily-bars) on all 372 signals — SHA \sha{9fea032}
\end{itemize}

\end{itemize}

\statusnotbuilt{} Requires \texttt{web/scripts/wave1\_entry\_filter.mjs} and \texttt{tools/wave1\_entry\_filter.py}.

\subsection{Accumulate Transition Trigger}

For every non-SPY ticker, on every emitted gate event $t$:
\[
  \text{is\_trigger}(i, t) = \bigl[D_{k,i}(t{-}1) = 0\bigr] \;\text{AND}\; \bigl[D_{k,i}(t) = +1\bigr]
\]
where $t{-}1$ is the immediately prior \emph{gate-event emission} for ticker $i$ (not the prior calendar day). No trigger for the first emitted row (no prior $D_k$ exists).

\subsection{Wave 1 Condition — Structure A}

\section{Exit Logic}

\statuspartial{} EXIT-F, EXIT-R9, EXIT-B active. EXIT-TIME (20d) \statusnotbuilt. EXIT-A and EXIT-H \statusremoved{} and must be reinstated.

All exits evaluated in this exact order per sentinel cycle (market hours):

\subsection{EXIT-F — Catastrophic Floor (\emph{always active})}

\begin{lstlisting}
if (current_price - entry_price) / entry_price <= -0.10:
    market sell immediately
\end{lstlisting}

Source: \texttt{sentinel\_monitor.mjs} lines~762--818. Fires during market hours only (line~773). Cannot be disabled. Threshold $-10\%$ applies to signal class CH2 (line~777).

\subsection{EXIT-R9 — Minimum Hold Guard (7 calendar days)}

\begin{lstlisting}
if age_days < 7:
    suppress all LOSING exits (EXIT-A, EXIT-B, EXIT-C, EXIT-TIME)
    allow WINNING exits regardless
    EXIT-F still always fires
\end{lstlisting}

\code{MIN\_HOLD\_DAYS = 7} — line~112. Production data (May~26 audit): 85\% of $D_k$ collapse exits recovered at 10--20~days; optimal hold projects 67.1\% WR from 41.3\%. Source: \texttt{TFE\_AUDIT\_MAY26\_2026.md} lines~94--98.

\statusremoved{} (\texttt{sentinel\_monitor.mjs} line~868). \textbf{Must be reinstated for v1.0.}

\begin{lstlisting}
if S_UF_i(t) >= 0.75  AND  P&L >= 0:   # winning position only

\statusremoved{} (line~936). Retain as REMOVED in v1.0. Replaced by EXIT-TIME.
