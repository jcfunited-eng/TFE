### 5.1 Local context, predictors and provenance

\[

\[

\eta\frac{(y_{j,n+1}-\hat y_{j,n+1})\psi_n^T}

Routine internal edits continue; a failed checkpoint blocks the dependent qualification/release claim, not unrelated authorized repairs.

| Checkpoint | Independent spot check and required record |
|---|---|
| Before first candidate compile | Compare actual diff/call graph with EX01–06, source/target provenance, native endpoint/units table, full-field consumers, state/codec ownership and bounds. Check that new code is actually mounted and old controllers cannot enter boot/restore/test/package routes. |
| Every five implementation commits, or daily while the slice is actively changing, whichever occurs first | A1 chooses an actual changed path and traces one observation through retained change to a native consumer; also inspects allocation, constants and test-predicate changes. G1 supplies the diff/evidence at that cadence. This is a process requirement, not an installed scheduler. |
| Before module-to-system promotion | Independently inspect a delayed-control case, a saturation/quiet case, an insufficient-resource rollback, and exact cold continuation. Recompute actual sizes/work and verify pre-update prediction residuals. Unit helper passes cannot replace these. |
| Before candidate freeze/release | Inspect the complete production path for semantic answer injection, external model inference, retired controller resurrection, default/fallback success, epsilon/tolerance inflation, skipped checks, inflated work limits and test weakening. Bind compiled native binary to source and candidate image. |
| After release | Read-only live observation of actual chronological progress, pressure/ear ancestry, latency, state continuity and resource behavior; no live training/perturbation inferred from audit permission. Live state/build must match the qualified artifact. |

Every accepted mechanism must map to its exact exception ID and consumer, or to an unchanged ratified law. Static text scanning is only a discovery aid: a renamed module or absent forbidden string cannot establish compliance. Review test predicates and fixture boundaries. A known target is allowed to the independent observer for scoring, never as an input to the pupil's controller. A design/source/test-only/package/live evidence column remains separate in the [machine-readable contract](guala_reconciliation/speech-learning-contract.json).

**Completion condition:** the canonical specification and reviewed handoff can be complete while organism development remains OPEN. The organism is complete only at its demonstrated, release-bound acceptance level. Current source/math review supplies no learned-speech or performance pass.
