## Appendix A — canonical target spec, RECOVERED
Source: project chat record, session "Guala 6/21 Evening" (2026-06-21),
authored by that session's Eve. Recovered verbatim 2026-07-03.

The 7th dimension preserves production's polarity slot. The dim-count
maps 1:1 to the substrate primitive set: 6 krimelack primitives per
-83 §1 + 1 polarity slot per v5_engine line 149. No tuning. No
archetypes. Phase is read from the krimelack at the binding window;
phase is NOT quantized into chi positions for cognition-path storage
(PSI_DIM=16 stays on the ψ-lattice settle path for spike triggering,
untouched).

Cognition is recall via complex inner product:
1. Each neuron computes its target state vector: target =
   grandurun_state(query_phases), query phases read from the neuron's
   krimelack bank after running the query through (no atlas write).
2. Vectorized over the neuron's atlas: scores = abs(atlas_matrix @
   conj(target)).
3. The binding with maximum |inner product| in that neuron casts ONE
   vote for its concept label.
4. Population aggregates: most votes across all neurons wins.
Max-pool per neuron, vote-count across population. Sum-pooling is
rejected — it biased toward dense chi regions.

Experience: each multi-modal moment delivers ALL applicable modalities
in the same binding window; per neuron, build the multi-modal phase
dict, compute the 7-dim state vector, append ONE binding labeled with
the concept. No band-replicate, no quantization. The state vector IS
the address.

What does NOT happen in the cognition path: no ψ-lattice argmax →
dominant_mode chi; no L6-TCL n_eff check before binding; no DSF
computation required for binding; no abs(v)>0.5 heuristic; no chi-band
replicate; no sum-pool.

Validated behavior (model_cognition_v2.py, 100 concepts × 1024
neurons): 1 modality 2.5% (≈chance) · 2 modalities 11.8% · 3
modalities 55.5% · 5 sensory no-language 92.5% · 6 full multi-modal
92.8%. Linear scaling: bindings ×80, recall time ×14.
