## Physical primitive

One event names a typed species, one source compartment, one mounted target
compartment, and one requested quantity. The transition moves:

```text
min(requested quantity, source quantity, destination free capacity)
```

The same quantity is subtracted from the source and added to the destination.
Any unmet request is reported as momentary output; it is not material, not
silently discarded, not appended to history, and not reinterpreted as a
cognitive score. The exact lane address remains in the transition result.

Source availability and destination capacity are physical constraints, not
heuristic caps. Capacity must be derived from mounted anatomy and declared
units before a production compartment is admitted.

## Organism boundary

The fluid manager is a sparse physical flow, not an owner or cognitive
scheduler. Only a reached mounted lane transitions. It does not poll all
species, compartments, neurons, or terminals. The complete chain must become:

```text
truthful body/environment event
-> body conversion or reservoir transition
-> sparse conservative pass-off(s)
-> local receptor/metabolic transition
-> local energy/channel/terminal availability
-> reached neuronal transition
```

Food, water, oxygen, rest, and sleep do not directly set recovery to true.
Their body conversions, units, capacities, transport paths, and local effects
must be separately derived. A missing path remains unavailable.
