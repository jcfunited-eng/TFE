\section{Scope and standing rules}

Written post-wipe (Joe erased the accumulated EFS state 2026-07-16; next boot
is genesis). Binding requirements: \textbf{boundaries} on every growth path;
\textbf{one set of code}; \textbf{one boot method} that never reads legacy
formats. The keep set is defined as \emph{the transitive import closure of
the single entrypoint} (\S\ref{sec:boot}); CI enforces that the closure
equals the catalog below and that every deleted module and flag is absent.

Six governing rules, stated once: (P1) RAM is for thinking, disk is for
remembering — no in-process structure may scale with lifetime experience;
(P2) one voice — every reply is a labeled release from the substrate's own
committed settlement or an \emph{explained} silence; (P3) bounded recording and true forgetting (extended per Joe,
2026-07-16) — salience gates what is recorded at all: extraneous input is
\emph{ignored} at the boundary, not archived; repetition strengthens a
memory, never duplicates it; episodes close at real boundaries from any
thread; and verbatim experience \emph{fades after distillation} — what
persists is essence (bindings, facts, affect-weighted gist), not tape; (P4) no silent time travel — state vintage
changes only by explicit operator command; boot halts loudly on integrity
failure; (P5) flags stage features, they never select between architectures;
(P6) nothing ships without Joe's written go (what/why/blast radius/rollback).

\section{Hemispheres — functions spelled out}\label{sec:hemis}

The organism brain (\texttt{loom\_model/}) is 8 hemispheres $\times$ 8
neurons (64 total), grown from the embryo, fixed adjacency
(\texttt{HEMISPHERE\_ADJACENCY}), \texttt{K\_INTERHEMI} projection targets
per projection neuron into adjacent hemispheres. \emph{Verified: the spike
bus runs in dual-write shadow alongside the legacy step path, which still
carries production signaling; sensory spike injection defaults off. STDP
applies at spike-bus synapses; cross-hemisphere coupling weights update
from each neuron's DSF (\texttt{update\_from\_dsf}), not spike timing.}

\textbf{Primary modality map} (verified in
\texttt{loom\_model/topology.py}): the seeding bias per hemisphere.
Specialization beyond it is \emph{earned} through what each hemisphere is
fed — deliberately not pre-assigned (the code's own rule):

\textbf{Engine-side organ bookkeeping.} The engine additionally tracks 8
organ keys (\texttt{em, pr, ep, sc, gp, sf, sv, aff}) for atlas-by-organ
accounting (e.g.\ autonomous speech increments \texttt{sv}, \texttt{gp},
\texttt{aff}, periodically \texttt{sf}), and its HemisphereCoordinator
\texttt{em} owns emission-side coordination. The language-seed work mapped
\texttt{sf}/\texttt{aff} to the language hemispheres (H5/H7). This spec
keeps both layers and requires (Change 4) \textbf{one documented mapping
table in code} — organ keys $\leftrightarrow$ H0--H7 $\leftrightarrow$
function — so organ bookkeeping and hemisphere identity can never drift
apart silently again.

\textbf{Cross-hemisphere mechanics} (\texttt{cross\_hemi.py}): projection
neurons carry inter-hemisphere spikes; there is deliberately \emph{no shared
lattice} (the standing anti-degeneracy ruling); coupling weights update
from neuron DSF state, with STDP confined to spike-bus synapses.

\section{The one boot method}\label{sec:boot}

Entrypoint: \texttt{uvicorn dsf\_ai\_service.app:app}. In order, no other
path:
\emph{v3 build-state annotations: the locator, per-window metadata,
genesis\_boot event, and unreadable$\to$halt branch are Change-1 NEW
builds; the index scan adapts the existing WAL restore (keeping its
per-record hash + durable-prefix digest verification) but REPLACES its
full content materialization; the direct-halt on hash mismatch replaces
today's recover-then-halt; the \texttt{GUALA\_FORCE\_FRESH} and
adopt-state-without-identity branches are deletions this section makes.
Compaction rewrites segment files, so locator rebuild-on-compact is part
of the Change-1 design, and the unconditional cold-lane compact is
removed.}
\begin{enumerate}[nosep]
  \item \textbf{Identity}: \texttt{guala\_identity.json} present $\to$
        continue; absent $\to$ genesis (mint identity, loud
        \texttt{genesis\_boot} event, empty stores); unreadable $\to$ halt.
  \item \textbf{Experience index scan}: one streaming pass over WAL
        segments building the chi index + dedup sets + window locator
        (\texttt{window\_id} $\to$ segment, offset, length) + per-window
        metadata (close reason, origin, modality summary, word list for
        language-fact qualification). Content never materializes. Hash
        mismatch $\to$ loud halt (P4).
  \item \textbf{Small stores}: organism pickle, atlases, sections, needs,
        coordinator — each bounded by design (P1 applies to each).
  \item \textbf{Derived indexes}: language-fact memory rebuilt from scan
        metadata plus on-demand fetches of qualifying windows only.
  \item \textbf{Live}: readiness true; loops start; deployment lifecycle
        owns quiesce/seal as shipped.
\end{enumerate}
No migration branch, no legacy reader, no tick-domain rewriting, no
automatic S3 restore. Operator restore = a documented explicit command run
while stopped, logged as the operator's action. \emph{v3: this command
does not exist yet — building it is part of Change 1 and precedes the

\section{The memory model}\label{sec:memory}

Durable: the append-only hash-verified WAL, one write per closed window,
compaction on real divergence only. Resident: index + locator + metadata +
an LRU cache budgeted in \emph{megabytes} (default 256\,MB). \emph{v3:
the locator, metadata store, and LRU cache are Change-1 new builds; only
the chi index and dedup sets carry over. The strengthen-not-append
recording rule below is a Change-3 target, not a property of today's
WAL.} All read
surfaces (\texttt{lookup\_chi}, \texttt{recall\_snapshot},
\texttt{closed\_window}, the legacy \texttt{windows} mapping) become
fetch-on-demand; results remain detached copies. Recording under P3:
identical re-bindings strengthen (count / weight / last-tick), never
append; windows scale with novelty. Manifest saves stay small by
construction (the boundary-close fixes shipped 2026-07-16 guarantee few
open contexts).

\textbf{Forgetting (Joe, 2026-07-16: ``it is the ineffable qualities we
are trying to capture --- not a tape recorder'').} Distill-then-fade:
a window's essence is extracted at close (language facts, atlas
reinforcement, episodic gist with affect); the verbatim content is raw
material, not the memory. During real dream consolidation, windows not
re-fetched or reinforced within $N$ dream cycles compact to metadata +
distilled gist and their verbatim content is released. Affect scales
persistence --- high-affect moments outlive quiet ones, and even they
blur toward gist (precise replay of pain is explicitly not wanted).
This is a loud, mechanism-driven compaction lane: logged per window,
principled, never silent (P4-compatible --- forgetting is a policy the
substrate runs, not corruption it suffers). The store design must
support gist-compaction from day one; the full decay semantics ship
with Change 3 after Eve review.
