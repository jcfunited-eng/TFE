## STANDING RULE (binding on every wC instance from today; goes in every handoff)
1. **One ledger.** All open work lives in docs/GL-LEDGER.md (this file, renamed on commit). New finds are APPENDED as ledger items — never spawned as new standalone briefs unless an item needs >1 page of spec, in which case the spec doc is written AND a ledger line pointing at it is added in the same turn.
2. **No silent supersession.** A document may only be superseded by a diff: the superseding text lists every item of the old doc with a disposition — CARRIED (ledger #), DONE (commit/task #), or DROPPED (Joe's explicit ruling, quoted). Anything unlisted is a leak and a wC failure.
3. **Session bookends.** Every wC session: FIRST ACT = ls-tree + read GL-LEDGER.md + diff it against repo/substrate reality (mark DONE items with evidence). LAST ACT = commit the updated ledger via c1's paste-ready command. The ledger is never allowed to be older than the last session.
4. **Find ≠ fork.** When wC finds a defect mid-review, the fix is added to the CURRENT open execution tier — the work in flight is finished, not abandoned for the shiny new hole.
5. **c1 mirrors:** c1 marks ledger items DONE with commit SHA + task # in the same commit chain as the work. "Done" without a SHA is not done.
6. **TEACHING CADENCE (proposed by wC, awaiting Joe's ratification).** Default state is TEACHING, not building. After Tier-1 deploy + Tier-2 validations: deploy freeze of at least 72h. During a freeze: no deploys (her container never restarts), content only — bundles, books, visits, family sessions — plus daily observation rows appended to this ledger: the four ladder metrics, atlas_health totals, attention skew, notable events. Build sprints open ONLY when observation surfaces a need or a gated item's gate clears, ship as ONE bundled deploy, then freeze again. The dream/unpause sequence (3.1) runs inside a freeze with a 48h observation tail. Exception: Stage 2 (3.5) deploys alone per its own rule. The ratio inverts permanently: building serves teaching, never the reverse.
7. **SMOKE BEFORE JOE (born 2026-06-11, daddy-bundle image crash).** Every UI-reachable path c1 ships is exercised end-to-end via the API with synthetic payloads BEFORE Joe is asked to touch it: a tiny PNG, a 1-second WAV, a full five-lane bundle, and one deliberately oversized/corrupt file to prove the failure path speaks. Pass = expected events visible in the event stream, no exceptions in the response. Joe's browser is the ACCEPTANCE bar, never the DISCOVERY bar. A "DONE" without a smoke-test transcript is not done.
