## Prepare, commit, and discard

`prepare(source)`:

- admits one immutable native joint-source episode;
- starts from the resident typed predecessor without decoding or rebuilding
  predecessor fields;
- evaluates each newly reached cohort through unchanged complete L0-L4 once;
- creates exact borrowed complete-field, perspective, and D1 admissions for
  reached neurons;
- advances the resident trace/mosaic/recognition/partial-cue transition from
  the same reached neuronal occurrence without a Python callback;
- encodes the successor `GLORUN01` envelope once;
- retains the candidate inside the same native runtime; and
- returns only a fixed-size token and truthful observation.

`commit(token)` moves the prepared successor into the active slot and clears
pending state. A wrong, consumed, or stale token refuses without mutation.

`discard(token)` drops the candidate and leaves every active byte, receipt,
clock, neuron, fractal, and observation unchanged. A second prepare while a
candidate exists refuses.

Save and readiness observe active state only. A pending candidate is never
reported as experience, learning, cognition, or current state.

## Persistence and atomic publication

Each checkpoint captures the active resident once and stages exactly one raw
`guala_organism.glorun` body. `guala_core.json` contains only its file name,
byte count, and SHA-256 receipt; it contains no base64 body or second materialized
fabric. The existing immutable whole-generation publisher verifies and
atomically advances the sole generation `CURRENT`. There is no second inner
organism `CURRENT`, owner, database, or fallback authority.

The native causal transition orders prepare, downstream causal settlement, and
commit/discard within the live organism. Checkpoint publication later makes the
then-active state durable. A failed or tampered raw checkpoint halts restore; it
cannot fall back to JSON cognition, genesis, a predecessor body, or an old
owner task.
