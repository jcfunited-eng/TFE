## Why it failed D3

1. **Typed-coordinate violation:** balanced-ternary carry can create or change
   a neighbouring digit whose typed DSF meaning is unrelated to the source
   coordinate. In the smallest counterexample, `1 + 1` becomes `(-1,+1)`;
   the second position did not exist in either one-trit input.
2. **Non-injective aggregate:** different local and neighbour decompositions
   can settle to the same word. The aggregate alone cannot preserve which
   physical causes participated.
3. **Cancellation is not perturbation:** two authenticated opposite arrivals
   can participate while producing zero net change. Participation, net
   perturbation, and later operative influence must remain distinct.
4. **Untyped edge constitution:** one polarity and one positional shift applied
   to an entire heterogeneous local word does not define which physical source
   quantity reaches which target state.
5. **Incomplete Krimelack physics:** the result has no ratified oscillator
   phase, winding, event, habituation, refractory, energy, or recovery update.
6. **No operative recurrence:** if the coupled result is never consumed, it is
   epiphenomenal arithmetic. If later cognition consumes it, that recurrent
   path and its stability must be specified and bounded.
7. **Topology authority absent:** current production has no authenticated
   anatomy/DNA law that admits an edge, polarity, direction, or positional
   mapping. Full-field `C_k` edges are relational field geometry, not neuronal
   `J_ij`.
8. **Physical resource proof absent:** the Python model can reject an abstract
   trit envelope, but it is not a native allocation/CPU/storage proof.
9. **Cross-clock cause remains unresolved:** placing fractals from separate
   clocks in one sum cannot establish common physical cause.

## Typed-routing follow-up audit

The next candidate treated `J_ij` first as sparse physical routing rather than
a numeric weight. That foundation is necessary but does not yet supply the
missing state-change physics.

Typed neuronal arrivals must not be inserted into `JointFieldInput` as extra
physical vertices. L0 normalizes that input and constructs complete physical
relation geometry. Inserting post-neuronal arrivals there would change the
meaning and output of frozen L0–L4 and would conflate physical `C_k` geometry
with sparse neuronal coupling.

The lawful implementation seam is a new synchronous boundary after complete
L4 delivery and before the final neuronal fractal:

```text
immutable whole-organism predecessor snapshot
    -> unchanged local L0-L4 deliveries
    -> typed generation-delayed sparse-neuron arrivals
    -> ratified persistent Krimelack state transition
    -> successor neuronal states and causally grown fractals
    -> atomic whole-organism replacement
```

The current `settle_neuronal_fractal` accepts only the target neuron's local
field perspective and its own predecessor fractal. It cannot consume a
neighbour arrival. Current mounted neurons contain no persistent Krimelack
state, coupling arena, or arrival arena. A coupling-only reached internal
neuron also cannot be represented because current neurons are created only
from physical source ports.

### Necessary carrier types

The following structure is necessary but deliberately has no invented arrival
payload or settlement equation:

1. `SparseNeuronCoupling`: stable source and target neuronal lineages,
   topology generation, topology receipt, and causal edge authority.
2. `NeuronCoupledState`: persistent exact Krimelack state and predecessor
   authority, distinct from the local DSF perspective and neuronal fractal.
3. `PredecessorNeuronArrival`: source/target lineage, predecessor organism
   generation and state receipt, source coupled-state receipt, edge/topology
   receipt, and the still-unratified typed physical payload.
4. `ReachedNeuronInput`: optional truthful local perspective plus canonical
   typed arrivals. This admits an internal neuron reached only by coupling
   without fabricating sensory field evidence.
5. `CoupledNeuronSettlement`: next persistent Krimelack state, every consumed
   arrival, optional local field authority, predecessor target state, resulting
   neuronal fractal, and one recomputable causal receipt.

Every transition must derive all arrivals from one immutable predecessor
snapshot, canonicalize and validate them, settle every reached target without
mutating the snapshot, then atomically commit all replacements. Cohort-by-
cohort mutation is not organism-wide causal simultaneity.

### Remaining irreducible physics question

Routing establishes where an arrival travels and preserves who caused it. It
does not define what physical Krimelack state changes when the arrival reaches
the target. Until that state and transition are exact, routing code would be
inactive scaffolding and may not be implemented or described as coupling.
