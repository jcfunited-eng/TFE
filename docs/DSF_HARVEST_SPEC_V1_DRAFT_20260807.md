# DSF Harvest Spec v1 — DRAFT 2026-08-07

Every claim wears a label: PROVEN (run filed), SUPPORTED (evidence,
pin pending), PENDING (declared, not run), DEAD (failed, kept as
record). Runs live in docs/CH4_LIVE_TIMING_AUDIT_20260731.md.

## 1. Architecture
- PERCEPTION (DSF kernel): reads structure (gates/patterns) and crowd
  state (herd energy/greed field) from price+volume alone. Decides
  WHAT and WHEN.
- INSTRUMENTATION (quant): sizing, costs, portfolio limits, referee
  statistics. Grades and sizes; NEVER steers. The moment quant
  features generate signals, we are band-mining again (12+ failures
  on record).

## 2. PROVEN
- Pattern law: qualifying pattern classes call direction 58.6-77.9%
  EVERY year 2016-2026, on four independent gate constructions
  (172,433 obs). [Addendum 6]
- Not drift-riding: in a fully inverted price universe the engine
  flips with the world — 93.9% long becomes 93.3% short, conviction
  distribution identical, zero same-direction anomalies across 1,873
  shared entries. [Addendum 7]
- Not a quant repackage: on 5,040 identical events the kernel (54.0%)
  beats momentum (52.3%), trend (52.2%), reversal (50.1%) and wins
  every disagreement battle. [Addendum 9]
- Crowd gate carries information: same events, true herd labels vs
  shuffled = +$646k vs -$485k over the decade (~$1.1M separation,
  +6.2pp win rate). [Addendum 10]
- Trap discrimination: the fade filter refuses herd-backed spikes and
  shorts hollow ones; exclusions (e.g. SHOP 08-05) behave as births.

## 3. MEASURED LIMITS (facts, not caveats)
- Single picks are half-weather: 1bp price noise rebuilds ~50% of the
  entry list; direction never flips. Judge ensembles only. [Add. 7-8]
- Dollar-truth is slow: clustered-trade batches reach 72% confidence
  only at ~200 trades (CH4 v1 pace: months). [Addendum 8]
- Winner's curse: entries on 20-29-case records realize 52.7% vs
  59.5% on 60-199-case records, all promised ~78%. 57% of v1 trades
  sit in the weakest bucket. [Addendum 8 ext 2]
- Fade dollars concentrate 2021-2026; near zero before. [Add. 10]
- CH4 v1 realized: 7,576 trades, 54.4% win, +0.60%/trade — thin,
  7.6 sd above coin. [Addendum 8]

## 5. THE GAUNTLET — no real dollars until a channel passes ALL
1. Knowability audit (every fill priced at-or-after its fact is
   knowable; as-of-issue records).
2. Mirror test (decisions flip with an inverted universe).
3. Noise floor (verdict survives 1bp perturbation at ensemble level).
4. Shuffle null (its gate beats scrambled labels).
5. Shelf test (beats each standard quant signal on its own entries,
   including disagreements).
6. Cost model (borrow/slippage/impact for ITS instruments). PENDING
   for CH3/CH6 shorts.
7. Live record: 20+ closures consistent with the decade replay.
