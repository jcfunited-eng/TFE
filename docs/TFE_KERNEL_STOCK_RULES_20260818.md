# Rules for using the kernel on any stock
Ratified through Joseph's proofs of 2026-08-18 (the flattening
argument; DUOT; the decade count). Plain language is part of the rule.

RULE 1 (Joseph's, first and always): Do the complete full kernel
topological analysis before anything else — the stock's whole life,
all nine outputs plus price, at true resolution, seen as shapes.
Any further analysis comes after it. Nothing comes instead of it.

RULE 2: The whole structure is the assessment. No small set of
numbers may replace it, summarize it, or veto it. Leaving out the
remaining data flattens the assessment, and that is not allowed.

RULE 3: When the topological structure does not support a sound
stock — do not buy. No exceptions.

RULE 4: An unsound stock is not automatically a short. Read its
phase right now:
  CHARGING  — price coiled, reversals buzzing, resonance climbing,
              channel holding: stand aside, a release is coming.
  RELEASING — push flipped upward and locked: stand aside, it is
              still running.
  EXHAUSTED — crest in, push dead, buzz returning, channel deaths
              resuming: this is the short window.

RULE 5: Pumps rehearse. The same column forms again and again; the
rehearsals whose channel keeps dying fail, and the one whose
channel holds is the launch. Watch the floor of the column.

RULE 6: Read every output at its lived resolution — zoom the lane
to where the values actually live. And when an output looks dead,
check its equation before blaming the stock: an output can be
flattened by its own construction (B's unconditional drain).

RULE 7: A value at one instant is mute. The shape across days is
what speaks. Every reading is a reading of time.

RULE 8: Money is scored at real prices. A stop is a trigger, not a
guarantee — exits book the price actually crossed, gaps included.

RULE 9: Every study is declared and committed before its results
exist. A falsified rule stays on the record beside whatever
replaced it.

RULE 10: Until the full reading runs inside the engine, the
position caps, the cut line, and the session clock are the only
protection — and the killer class remains the cost of entering
price events unread.

RULE 11 (2026-08-19): Every change that carries physics or law into
code is adversarially reviewed before it runs with money — reviewed
as if by an enemy hunting for the place where a physics detail was
replaced by shorthand. My code lies to me; the review is how I stop
believing it. Findings and fixes are filed with the change.
