================================================================================
TRANSMISSION LINE DESIGN (50 Ω Coplanar Waveguide)
================================================================================

Objective: Route 2.87 GHz signal from SMA input to antenna with minimal loss

Design frequency: 2.87 GHz (NV Larmor)
Wavelength in material: λ = c / (f × √εᵣ) = (3×10⁸) / (2.87×10⁹ × 1.88) = 55 mm

CPW (Coplanar Waveguide) impedance formula:
  Z₀ = (120π / √εᵣ_eff) × ln[(2w + 2s) / (πw)]

  where:
    w = trace width
    s = gap width (trace to ground)
    εᵣ_eff ≈ (εᵣ + 1) / 2 (for CPW on 0.508 mm substrate)

Target: Z₀ = 50 Ω

Solving for w and s:
  For Rogers RO4003: εᵣ_eff ≈ 2.27
  Target: w = 1.27 mm, s = 0.64 mm (from design curves)

Signal path:
  1. SMA input @ (48 mm, 15 mm)
  2. Straight CPW line → (35 mm, 15 mm) [13 mm length, quarter-wavelength ≈ 13.75 mm]
  3. Antenna element @ (22 mm, 15 mm)

CPW dimensions (Top layer):
  Trace width (w): 1.27 mm ±0.1 mm (CRITICAL)
  Gap to ground (s): 0.64 mm ±0.1 mm (CRITICAL)
  Trace length: 13 mm ± 0.5 mm
  Trace thickness: 35 μm (copper thickness)

Impedance verification:
  Network analyzer @ 2.87 GHz:
    S₁₁ (return loss): < -10 dB (good matching)
    S₂₁ (transmission): > -3 dB (low loss)

ANTENNA ELEMENT DESIGN
================================================================================

Type: Microstrip patch antenna (simplified)
Resonance: 2.87 GHz
Coupling: Magnetic field (radiates near H field)

Geometry:
  Antenna patch:
    Length: λ/2 in material ≈ 27.5 mm ÷ 1.88 ≈ 14.6 mm
    Width: λ/4 in material ≈ 7 mm
    Location: (22 mm, 15 mm) center
    Shape: Rectangle (simple, efficient)
    Orientation: Horizontal (length along x-axis)

  Feeding:
    Type: Direct connection to CPW line
    Location: Center of patch length
    Feed line width: 1.27 mm (matches CPW)

  Radiation pattern:
    Predominant: Magnetic field (H), not electric field (E)
    Radiation lobe: Perpendicular to board (toward diamond)
    Gain: Approximately 3 dBi (omnidirectional in horizontal plane)

Ground plane:
  Coverage: Full bottom layer (Layer 2)
  Vias: 4× ø0.5 mm vias around SMA connector (connect top/bottom grounds)
  Via spacing: 2 mm apart (RF grounding)

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

If S₁₁ > -10 dB (impedance mismatch):

Possible causes:
  1. Trace width too wide or too narrow
     Solution: Adjust trace width by ±0.1 mm in new iteration

  2. Substrate thickness wrong
     Solution: Verify PCB thickness is exactly 0.508 mm

  3. SMA connector impedance mismatch
     Solution: Check connector specifications (must be 50 Ω)

  4. Via placement bad
     Solution: Move vias further from feed point (>5 mm away)

If S₂₁ < -3 dB (excessive loss):

Possible causes:
  1. Substrate loss (tanδ too high)
     Solution: RO4003C is already low-loss; check if correct material used

  2. Copper surface oxidation
     Solution: ENIG finish prevents this; check if gold plating applied

  3. Trace contamination
     Solution: Clean board with isopropyl alcohol before testing

If antenna doesn't radiate (B field not measured):

Possible causes:
  1. Antenna patch dimensions wrong
     Solution: Verify patch is exactly 14.6 mm × 7.0 mm

  2. Feed point in wrong location
     Solution: Feed should be at center of patch length (7.3 mm)

  3. Ground plane not connected
     Solution: Check vias are plated and connected to bottom copper
