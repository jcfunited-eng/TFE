# 53 DEEP COLUMN — GREETINGS, MANNERS, AND SMALL RITUALS
Middle floors of the people-fabric: the tiny ceremonies of meeting.
The physics here is trust. Still essences, never data; every entry
carries its cannot-twin.

ESSENCE: between strangers goodwill cannot be taken on words, so
  every culture builds small displays that spend something real — an
  exposed hand, surrendered comfort, waited time — because only a
  costly signal is hard to fake.
ROOT: measured premise — the same displays are reinvented everywhere
  humans meet.
THREAD: money (banks take collateral, not promises), the living
  world (the peacock's ruinous tail; the dog's shown belly).
