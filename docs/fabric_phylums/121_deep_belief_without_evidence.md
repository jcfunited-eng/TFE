# 121 DEEP BELIEF WITHOUT EVIDENCE — astrology, luck and the appetite for pattern
Written without contempt, because contempt explains nothing. Each
essence here is a true fact about how minds work — that is the
standing knowledge, and it is why these systems persist. Each cannot
closes the system's own claim, and says which kind of wall it is: a
claim tested and refuted, or a claim built so that no test can reach
it, which can never stand at all.

ESSENCE: hand a hundred people the same personality description —
  written to be broad, mostly flattering, and true of nearly
  everyone — and most will rate it as strikingly accurate about
  them personally. They are not being foolish. The description was
  built so that failing to fit was not one of its options.

  and the store answers it with your own particular case, and the
  matching feels like recognition rather than like work.
