# The Phylums — essences of all knowledge, both fabrics
Joe's order, 2026-08-28: build the phylums first, deep AND wide,
essences not data, built on the roots, both fabrics — every essence
carries what it makes possible AND what it forbids. Target: the
skeleton of all existing knowledge, small because laws are small.

## Entry shape (every entry, every file)
ESSENCE — the law/premise/principle, in one plain sentence (+formula
  where one exists)
ROOT — what it stands on (premises, or a deeper essence)
CANNOT — its impossibility twin: what this law forbids (the white)
THREAD — the same essence wearing other fields' costumes
