M1 Descriptor layer (in-process, every sentence, no network):
   extract the sentence's sensory descriptors via the existing
   TOUCH/SMELL/TASTE_LIBRARY map; generate the descriptor-profile
   physics waveforms ONCE per sentence (generate_sensory_signals —
   real descriptor physics, NOT the banned hash-per-word fake;
   update its GATING comment to name intake paths as legitimate
   callers per this doctrine).
M2 In-window delivery to the BRAIN: cache per -191's exact
   convention (_last_read_modal_signals = {"tactile"/"olfactory"/
   "gustatory": wf, only lanes whose descriptors actually appear}
   + wall-clock stamp; SENSE_BINDING_WINDOW_SEC unchanged).
   _enqueue_organism_remember snapshots in-window into the queue
   item (word, sight, sound, modal); _organism_signal_with_senses
   merges lanes. Embryo's growth composite already accepts these
   lanes (-191 N4) — zero organism-side change.
M3 LLM layer (bounded, existing machinery): lookup_grounding
   grounds the most recent UNGROUNDED noun from whatever she is
   currently taking in (engine keeps a small recent-nouns ring;
   ungrounded = no lookup_grounded event for the term). Its
   returned sensory sentence flows through read_sentence — which
   after M1/M2 delivers its senses to the organism in-window with
   the noun. Rate/gates UNCHANGED (interleave every 3 chunks,
   block schedule §8, LOOKUP_AUTONOMOUS, 10s timeout, one
   gpt-4o-mini sentence per call). Falls back to picture titles
   when intake is idle.
M4 Shell-atlas writes stay where they exist today — this ADDS the
   brain everywhere, it moves nothing.
M5 Honest sourcing stands everywhere: lanes fire ONLY for real
   descriptor words present in the text. No sensory word, no lane.
   No invention, no shims, no new constants.
