## Why context fission does not repair it

The shared context cannot serve as identity.  Removing it leaves only the
small action/place distinction.  That cannot make the failed auditory
direction selective:

- the correct `down` auditory mismatch count remains 143 before contextual
  help;
- the correct `left` auditory mismatch count remains 19;
- the `go` query already locks the wrong `down` auditory assembly without
  contextual help.

Thus there is no lawful choice between “count shared context” and “discard
shared context”:

- counting it locks every candidate;
- discarding it leaves correct candidates unresolved and a wrong candidate
  already resonant.

Changing the number of context copies or weighting context against sound
would be a tuned score and was not attempted.

## Nonlinear-attractor honesty boundary

An attractor does not remove the need for a relation.  It moves the relation
into its basin boundary.

For finite learned exemplars \(X_i\), a nonlinear potential such as

\[
V_T(Q)=\prod_i\sum_j(Q_j-X_{i,j})^2
\]

creates a scalar distance energy.  Gradient settlement is then a
score/nearest-exemplar classifier in dynamic form and flattens the explicit
field.  It is prohibited.

A componentwise potential avoids the scalar but lets different coordinates
settle to different exemplars, producing a synthetic cross-product that no
lived episode supports.

An exact oscillator that locks only on equal frequencies returns to the
already falsified exact-equality relation.  Widening its lock region requires
a coupling radius, phase tolerance, finite convergence cutoff, or competing
basin boundary.  Unless that boundary is independently derived from physical
law, it is a developer constant.

Context clamping is also insufficient: the different-command challenge shows
that a contextual attractor can settle the expected action despite the wrong
sound.  That would be context manufacturing hearing.

Therefore no versioned nonlinear profile is promoted from this result.
