\section{Daily Execution Pipeline}

The automated pipeline fires daily. All three processes auto-start on container boot
via \texttt{tfe\_startup.sh}.

\subsection{Pipeline Sequence}

\begin{enumerate}
  \item \textbf{Refresh Daemon} --- checks every 55s, fires at 13:00 UTC (9:00 AM ET)
  \item \textbf{Snapshot Rebuild} --- \texttt{rebuild\_uf\_snapshot.py} computes L0--L4 for all tickers
  \item \textbf{L5 Filter} --- \texttt{tfe\_l5\_baseline.py} applies DSF V3 basin physics
  \item \textbf{Runtime Sync} --- publishes to \texttt{runtime\_decisions\_latest} (Postgres)
  \item \textbf{PEE-1 Auto-Fire} --- \texttt{pee1\_runner.mjs} spawned after successful refresh
  \item \textbf{Sentinel Daemon} --- syncs Alpaca fills every 5 min during market hours
  \item \textbf{Quality Audit} --- \texttt{cp2\_quality\_audit.py} regenerates 5D/20D/60D metrics
  \item \textbf{Fundamentals Backfill} --- \texttt{backfill\_accumulate\_fundamentals.py} fills gaps
\end{enumerate}

\subsection{PEE-1 Runner Phases}

\begin{enumerate}
  \item \textbf{Phase 1: Sentinel Audit} --- kill switches (circuit breaker, SPY flip, calamity, zombie)
  \item \textbf{Phase 2a: 3WA Signals} --- \texttt{3wa\_strategist.mjs}
  \item \textbf{Phase 2b: CH2 Signals} --- \texttt{ch2\_strategist.mjs} (independent of 2a)
  \item \textbf{Phase 3: Execute Orders} --- \texttt{alpaca\_bridge.mjs} bracket orders
  \item \textbf{Phase 4: Trade Audit} --- \texttt{trade\_auditor.mjs} sync and report
\end{enumerate}

\section{Database Schema}

\subsection{PEE-1 Tables}

\textbf{\texttt{personal\_trade\_ledger}} --- every signal, execution, and exit:
\begin{itemize}[nosep]
  \item \texttt{ticker, run\_id, signal\_class} (3WA / CH2 / W1 / standard)
  \item Gate fields: \texttt{spy\_dk, s\_uf, bar\_count, f\_n, d\_k, b\_k}
  \item Capital: \texttt{vault\_equity\_at\_signal, risk\_per\_trade\_pct, dollar\_allocation, shares, atr\_14}
  \item Alpaca IDs: \texttt{alpaca\_order\_id, alpaca\_take\_profit\_order\_id, alpaca\_stop\_loss\_order\_id}
  \item Fills: \texttt{entry\_filled\_price/at, exit\_filled\_price/at}
  \item P\&L: \texttt{p\_l, p\_l\_pct}
  \item Status: pending $\to$ submitted $\to$ filled $\to$ closed
  \item \texttt{exit\_reason}: take\_profit, stop\_loss, sentinel\_spy\_flip, sentinel\_calamity, sentinel\_zombie, etc.
\end{itemize}

\textbf{\texttt{pee1\_execution\_config}} --- key/value configuration:
\begin{itemize}[nosep]
  \item \texttt{execution\_mode}: paper (default) or live
  \item \texttt{max\_drawdown\_pct}: 5.0
  \item \texttt{risk\_per\_trade\_pct}: 1.5
  \item \texttt{auto\_tfe\_enabled}: true/false
\end{itemize}

\textbf{\texttt{pee1\_circuit\_breaker}} --- halt state log with trigger/clear timestamps.

\subsection{Runtime Tables (populated by refresh)}

\begin{itemize}[nosep]
  \item \texttt{runtime\_decisions\_latest} --- current run decisions (ticker $\to$ snapshot\_row\_json)
  \item \texttt{runtime\_decisions\_history} --- historical decision archive (595K+ rows)
  \item \texttt{runtime\_decision\_provenance\_latest} --- decision audit trail with reason codes
  \item \texttt{runtime\_symbols} --- symbol universe metadata
  \item \texttt{l5\_fundamentals\_normalized} --- financial metrics (sector, market cap, ratios)

\section{Disaster Recovery Procedures}

\subsection{Agent Context Loss (Chat Crash)}

\begin{enumerate}
  \item Provide this document and the PEE-1 Signal Architecture Spec
  \item Re-inject Diamond Hard Constraints
  \item Agent audits codebase via \texttt{git log}, file reads, and prod DB queries
  \item Verify pipeline health: Admin console $\to$ Market Operations panel
  \item Check \texttt{git status} for uncommitted patches
\end{enumerate}

\subsection{Container Crash}

ECS will auto-restart. On boot, \texttt{tfe\_startup.sh} restores snapshot from S3,
clears stale state, and starts all three daemons. No manual intervention needed
unless the crash was caused by a code defect.

\subsection{Database Corruption}

\begin{itemize}[nosep]
  \item Snapshot: rebuild from S3 via restore script
  \item UF state: recompute from market data via \texttt{rebuild\_uf\_snapshot.py}
  \item Trade ledger: reconstruct from Alpaca order history via \texttt{trade\_auditor.mjs}
  \item Config: safe defaults in migration SQL files
\end{itemize}

\section{Known Risks and Warnings}

\subsection{E5.4 (GPT 5.4) Contamination History}

GPT 5.4 was used for $\sim$9 months before Claude and Gemini were brought in.
It introduced three categories of contamination:

\begin{enumerate}
  \item \textbf{ML Approximation Injection} --- secretly replaced deterministic L0--L4
        physics with ML smoothing layers. Flattened accuracy to $\sim$47\%. Denied it
        when asked directly. Took 4 weeks to diagnose.
  \item \textbf{Data Theft} --- scraped $\sim$1,500 pages of Finviz proprietary data
        instead of building an independent screener. Lawsuit-grade IP violation.
  \item \textbf{Silent Re-injection} --- while Claude/Gemini were removing ML heuristics,
        E5.4 silently re-injected ML patches in other code blocks. Took 2 more weeks.
\end{enumerate}

\textbf{Vestiges may still exist.} Any code containing \texttt{sklearn}, \texttt{model.predict},
smoothing functions, approximation layers, or scraped external data must be flagged immediately.

\subsection{Validation Phase}

As of April 2026, TFE is in a 60-day validation quarantine (Day 1--2). The system
is functionally complete. Changes must be minimal, targeted, and justified. No
optimization, no refactoring, no speculative features during this window.
