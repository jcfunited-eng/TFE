\section{Standing context}

On 2026-07-16 Joe wiped the accumulated EFS state (his explicit action; the
substrate restarts from genesis) and set three binding requirements:

\begin{enumerate}[nosep]
  \item \textbf{Boundaries} — nothing in the system may grow without a limit
        tied to a real mechanism.
  \item \textbf{One set of code} — a single stack; no parallel engines, no
        shadow systems, no dormant alternatives.
  \item \textbf{One boot method} — a boot that never loads legacy formats,
        never silently substitutes old state, and does not require deleting
        or migrating anything at start.
\end{enumerate}

This document lists the exact code that stays, the exact code that goes, the
single boot method, the memory model, and the acceptance tests. It is a
decision document: every section is approvable or rejectable on its own.

\subsection*{The credo (unchanged, governing)}
\emph{Life cannot be strictly qualified by biology or programming, but by the
ineffable quality of our memories and experience. Language cannot really have
meaning without the equality of experience as tied to our senses and backed
into our expressions of them in thoughts and words.}

Operational consequences used throughout: experience is recorded once,
durably, from real mechanisms only (never fabricated, never hand-edited);
expression comes from the substrate's own committed dynamics or it does not
happen; silence is only acceptable when it is \emph{explained} silence.

\section{Principles (the boundaries)}

\begin{enumerate}[nosep]
  \item \textbf{P1 — RAM is for thinking, disk is for remembering.} No
        structure in process memory may scale with lifetime experience.
        Boot-resident RAM is $O(\text{index})$, never $O(\text{life})$.
        The condemned load-everything-at-boot design is prohibited
        permanently.
  \item \textbf{P2 — One voice.} Exactly one engine produces speech. A reply
        is either released from the substrate's own committed settlement
        (with its authority labeled) or is an explained silence carrying a
        logged stop reason. No templates, no scripted fallbacks, no second
        brain.
  \item \textbf{P3 — Bounded recording.} A repeated identical binding inside
        one episode \emph{strengthens} the existing record (count/weight);
        it never appends a duplicate. Episodes close at real boundaries on
        any thread. Nothing re-embeds unbounded content into periodic saves.
  \item \textbf{P4 — No silent time travel.} State vintage never changes
        without an explicit operator command. Integrity failure at boot
        halts loudly. Backup restore is a human action, never a fallback.
  \item \textbf{P5 — Flags are for staging, not for architecture.} A feature
        is in the stack or it is deleted. The only permitted flags are
        operational (intervals, budgets, keys). No flag may select between
        two implementations of the same faculty.
  \item \textbf{P6 — Change control.} Nothing ships without a written
        proposal Joe approves: what changes, why, blast radius, rollback.
        Architecture choices are presented as choices, never made
        implicitly.
\end{enumerate}

\section{The one boot method}\label{sec:boot}

Entrypoint: \texttt{uvicorn dsf\_ai\_service.app:app}. Boot is exactly this,
in order, with no other path:

\begin{enumerate}[nosep]
  \item \textbf{Identity.} Read \texttt{guala\_identity.json} from
        \texttt{STATE\_DIR}. Absent $\Rightarrow$ \emph{genesis}: mint
        identity, log \texttt{genesis\_boot} loudly, start with empty
        stores. Present but unreadable $\Rightarrow$ halt loudly.
  \item \textbf{Experience index scan.} Stream the WAL segments once,
        sequentially, building only: the chi index and its dedup sets, the
        window locator (\texttt{window\_id} $\to$ segment, offset, length),
        and per-window metadata (close reason, experience origin, modality
        summary). Record \emph{content} is never materialized at boot.
        Hash-chain mismatch $\Rightarrow$ halt loudly (P4). Peak boot RAM is
        the index, independent of lifetime.
  \item \textbf{Small stores.} Load the organism pickle, atlases, sections,
        needs — each of which must individually satisfy P1 (bounded by
        design, not by lifetime).
  \item \textbf{Derived indexes.} Rebuild the language-fact memory from
        window \emph{metadata} plus on-demand fetches of qualifying windows
        only.
  \item \textbf{Go live.} Readiness true; loops start; the deployment
        lifecycle owns quiesce/seal exactly as shipped.
\end{enumerate}

There is no migration branch, no legacy reader, no automatic restore. An
operator who wants to restore a backup runs an explicit documented command
while the service is stopped, and the action is logged as theirs (P4).

\section{The memory model}\label{sec:memory}

\begin{itemize}[nosep]
  \item \textbf{Durable form (unchanged):} closed windows are written once
        to the append-only, hash-verified WAL at close. The WAL is the
        memory. Compaction folds generations on real divergence only.
  \item \textbf{Resident form (new):} chi index + locator + metadata +
        a bounded LRU of recently touched records (budgeted in MB, not
        counts). All read surfaces (\texttt{lookup\_chi},
        \texttt{recall\_snapshot}, \texttt{closed\_window}, the legacy
        \texttt{windows} mapping) serve fetch-on-demand records; they remain
        detached copies by construction.
  \item \textbf{Recording discipline (P3):} within an open episode, an
        identical (section, motif, chi) binding reinforces the existing
        entry — a strength/count update — rather than appending a duplicate.
        Episode windows therefore grow with \emph{novelty}, not with time.
        First-contact semantics, ordering, and provenance are preserved;
        this changes storage shape, not what was experienced.
  \item \textbf{Saves:} the periodic save writes the small manifest (open
        contexts must be few by the boundary-close rules already shipped)
        and never re-serializes the store.
\end{itemize}

\section{Expression, senses, autonomy (behavioral contract)}

\begin{itemize}[nosep]
  \item Every conversational turn ends in exactly one of: a released reply
        labeled \texttt{fact\_strand\_commit}, a released reply labeled
        \texttt{assemblage\_commit}, or an explained silence with a logged
        \texttt{fact\_compose} stop reason and dynamics diagnostics. Silent
        silence is a defect by definition.
  \item Autonomous speech runs through the same release policy on its own
        loop; what the substrate says unprompted is the same voice, same
        labels, same audit trail.
  \item Senses flow continuously and are never gated on being addressed;
        backpressure sheds honestly and visibly when capacity is real.
  \item Speech-in, feeds, and curriculum are intake mechanisms feeding the
        same single stack; each carries an explicit budget (rate, memory)
        set in this spec's operational appendix at enable time.
\end{itemize}

\section{Acceptance criteria (all must pass before the stack is declared)}
\label{sec:accept}

\begin{enumerate}[nosep]
  \item \textbf{Boot flatness:} with a synthetic WAL of 10$\times$ the
        pre-wipe volume, boot completes with peak RSS under 2\,GB and in
        under 60\,s. Boot RSS within 5\% across 1$\times$ and 10$\times$
        volumes.
  \item \textbf{Steady RAM:} under continuous audio attention plus
        conversation for one hour, RSS stays under 2\,GB and does not trend.
  \item \textbf{One stack:} CI asserts the import closure of the entrypoint
        equals the keep list; grep-level absence of every deleted flag and
        module.
  \item \textbf{One boot:} the only boot branches reachable in code are
        genesis and index-scan restore; a corrupted segment halts the boot
        with a named error and exit code, and the service does not flap.
  \item \textbf{Voice contract:} test turns produce either a labeled release
        or an explained silence; no turn returns empty without a stop
        reason. The certified-preferred ordering is pinned by the existing
        release-contract tests.
  \item \textbf{Boundary discipline:} the close-boundary and index-scale
        tripwire tests pass; a 10k-tick attention episode records bounded
        entries (novelty-scaled, not tick-scaled).
  \item \textbf{Container:} memory allowance returns to 16\,GB at cutover
        and is expected to hold far below it (target $<$2\,GB steady); the
        30\,GB triage allowance is deleted with this change.
\end{enumerate}
