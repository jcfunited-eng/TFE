## Classify the algorithm, not its name

Deterministic execution does not establish absence of ML. Python versus Rust,
absence of gradient descent, absence of a framework, a ternary representation,
and names such as physical, resonance, stress or conductance do not classify an
algorithm. An experience-trained value table is still learned decision control.
An imported neural-network model remains an ML asset even when its runtime is absent.

Use separate fields for algorithm class, architecture disposition, evidence level,
and artifact/runtime scope. A method can have multiple classes; split distinct
causal stages rather than hiding a forbidden stage under an allowed wrapper.

| Class | Required description and disposition |
|---|---|
| `reward_learning` | Learned action/return estimates, reward objective, exploration and policy read. Forbidden as pupil decision authority. Includes ordinary tabular methods without neural networks. |
| `example_matching` | Stored examples, prototypes, transition keys or similarity-based responses. State whether examples are learned or authored. Forbidden as a substitute for distributed physical recognition/recall. |
| `hand_authored_policy` | Rules, priorities, semantic dictionaries, thresholds, scores or canned continuations that choose pupil behavior. Deterministic does not make these physical cognition. |
| `field_projection` | Exact fields discarded, rescaled, quantized, keyed or overwritten. Record the lost source, timing, magnitude and joint relationships. No full-field claim. |
| `associative_parameter_update` | Exact state variables and update equation, including targets and adaptation source. Do not call it material physics without independently justified units, constitutive derivation and causal evidence. |
| `physical_model_unverified` | A claimed physical transition whose derivation, binding or acceptance is incomplete. This blocks qualification; it is not a physics clearance. |
| `deterministic_transduction` | Signal conversion with specified coefficients, topology, clock, units and precision. Filters and waveform generation alone are not learned policies. Their fidelity and causal use still require verification. |
| `canonical_kernel` | Unchanged L0–L4 source custody. Kernel immutability does not certify a downstream caller's field delivery. No kernel modifications without Joe's explicit approval. |
| `state_transport` | Custody, serialization, ingress, world actuation or observation. Prove it cannot invent decisions, conceal failures, change memories or substitute outcomes. |
| `ml_model_asset` / `ml_inference_code` | Packaged models, trained weights, framework inference, external model APIs or speech/image recognition. Record both presence and actual mounting; neither implies the other. |
| `unknown` | Missing classification, native provenance, dynamic resolution or external-process evidence. Blocks an ML-free claim and release qualification. |

Physical adaptation is not exempt from inspection. Show which local physical
quantity changes, why it changes, how units and resource accounts close, how it is
retained, and how its later causal use follows the ratified law. If the mechanism
instead fits parameters to an example, target, loss or reward, name that operation.
Do not redefine ML solely to exclude Guala's current implementation.

For terminology, NIST describes ML in terms of systems adapting and learning from
data; a library requirement is not part of that definition. This project's verdict
comes from the actual update and decision equations, not an external certification.
[NIST glossary](https://csrc.nist.gov/glossary/term/machine_learning).
