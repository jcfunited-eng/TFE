\subsubsection{2.2 Refresh wrapper execution

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist

\item
  Run quote cache refresh
  (\texttt{web/scripts/build\_screener\_quote\_cache.py}) unless

  disabled.

  Resolve oracle short-cycle execution plan.

  Run validation gate
  (\texttt{web/scripts/run\_validation\_gate\_v1.mjs}) and require
  \texttt{status=pass}.

\begin{itemize}
\tightlist

  Post-L5/pre-oracle checkpoint persisted locally and optionally
  S3-backed.
\item

\subsection{3. L5 Policy Learning: Current
Implementation}\label{3-l5-policy-learning-current-implementation}

\subsubsection{3.1 Data sources and
modes}\label{31-data-sources-and-modes}

\texttt{l5\_policy\_learning\_pipeline.py} supports:

\begin{itemize}
\tightlist
\item
  \texttt{POLICY\_SOURCE\_MODE}:

  \begin{itemize}
  \tightlist
  \item
    \texttt{replay} (default)
  \item
    \texttt{rowtrace}
  \item
    \texttt{hybrid} (merge rowtrace-first with replay fallback)
  \end{itemize}
\item
  \texttt{EVAL\_MODE}:

  \begin{itemize}
  \tightlist
  \item
    \texttt{replay} (default)
  \item
    \texttt{rowtrace}
  \end{itemize}
\end{itemize}

I/O mode (\texttt{TFE\_L5\_POLICY\_IO\_MODE} via
\texttt{l5\_postgres\_io.py}):

\begin{itemize}
\tightlist
\item
  \texttt{file}
\item
  \texttt{hybrid} (try Postgres, fallback file)
\item
  \texttt{postgres} (strict)
\end{itemize}

\subsubsection{3.2 Structural keying (L4 -\textgreater{} L5 cell
mapping)}\label{32-structural-keying-l4---l5-cell-mapping}

Both policy generation and evaluation build PSCF cell keys from
structural fields:

\begin{itemize}
\tightlist
\item
  regime
\item
  D, M-sign, R\_rev, U bucket
\item
  C, P bucket, B-sign
\item
  S bucket, R bucket
\item
  optional CD bucket by regime mode
\item
  optional stability bucket
\item
  optional IRF phase suffix
\item
  optional Spider Eyes suffix
\end{itemize}

Key functions:

\begin{itemize}
\tightlist
\item
  Row-trace keying: \texttt{\_row\_trace\_cell\_key},
  \texttt{\_row\_trace\_cell\_key\_candidates}
\item
  Runtime state keying: \texttt{\_state\_cell\_key},
  \texttt{\_state\_cell\_key\_candidates}
\end{itemize}

Key schema string embedded in artifacts:

\begin{itemize}
\tightlist
\item
  \texttt{regime\ +\ D\ +\ M\_sign\ +\ R\_rev\ +\ U\_bucket\ +\ C\ +\ P\_bucket\ +\ B\_sign\ +\ S\_bucket3\ +\ R\_bucket3\ +\ CD\_bucket\_opt\ +\ PH\_opt\ +\ SE\_opt}
\end{itemize}

\subsubsection{3.3 Decision selection and explicit optimization
guards}\label{33-decision-selection-and-explicit-optimization-guards}

Cell-level decision picks best among
\texttt{\{Accumulate,\ Hold,\ Avoid\}} using:

\begin{itemize}
\tightlist
\item
  default objective: weighted mean excess vs SPY by horizon
  (\texttt{SELECTION\_OBJECTIVE=excess})
\item
  optional objective: mean action return
  (\texttt{SELECTION\_OBJECTIVE=action\_return})
\end{itemize}

Explicit hold guards for non-Hold outcomes:

\begin{itemize}
\tightlist
\item
  minimum action edge (\texttt{TFE\_POLICY\_MIN\_ACTION\_EDGE})
\item
  minimum margin to second-best
  (\texttt{TFE\_POLICY\_MIN\_ACTION\_MARGIN})
\item
  minimum winrate (\texttt{TFE\_POLICY\_MIN\_ACTION\_WINRATE\_PCT})
\end{itemize}

If a guard fails, decision is forced to \texttt{Hold} with reason
markers in decision stats.

\subsubsection{3.4 Replay generation
specifics}\label{34-replay-generation-specifics}

Replay generation (\texttt{\_generate\_policy\_from\_replay\_dataset}):

\begin{itemize}
\tightlist
\item
  Computes UF state per bar using
  \texttt{compute\_uf\_structural\_state}.
\item
  Tracks anomaly flags from decision guard/hardening.
\item
  Scores with two tracks per cell:

  \begin{itemize}
  \tightlist
  \item
    clean samples (no anomaly)
  \item
    all samples
  \end{itemize}
\item
  Selection policy:

  \begin{itemize}
  \tightlist
  \item
    use clean-sample stats if available
  \item
    fallback to all-sample stats when clean empty
  \end{itemize}
\end{itemize}

Includes symbol timeout and state-compute timeout controls.

\subsubsection{3.5 Merge, anomaly overlay, eval,
promotion}\label{35-merge-anomaly-overlay-eval-promotion}

Merge behavior:

\begin{itemize}
\tightlist
\item
  Primary-first, secondary fallback (\texttt{\_merge\_policies}).
\item
  Optional low-support filter for primary via
  \texttt{TFE\_POLICY\_MIN\_PRIMARY\_CELL\_SAMPLES}.
\end{itemize}

Anomaly overlay:

\begin{itemize}
\tightlist
\item
  \texttt{\_overlay\_anomaly\_profiles} fills missing anomaly profile
  from anomaly-watch policy.
\end{itemize}

Evaluation:

\begin{itemize}
\tightlist
\item
  \texttt{\_evaluate\_policy} on replay dataset
\item
  \texttt{\_evaluate\_policy\_rowtrace} on row-trace dataset
\item
  Produces per-horizon summaries for 5/20/60 including:

  \begin{itemize}
  \tightlist
  \item
    excess vs SPY
  \item
    outcome-over-index
  \item
    mapping rates
  \item
    anomaly-accounted variants
  \end{itemize}
\end{itemize}

Promotion gate (\texttt{\_compare\_candidate\_vs\_current}):

\begin{itemize}
\tightlist
\item
  promote only if all true:

  \begin{itemize}
  \tightlist
  \item
    aggregate delta excess (anomaly-accounted mean) \textgreater= 0
  \item
    delta outcome-over-index \textgreater= 0 for all horizons
  \item
    mapping rate delta \textgreater= 0 for all horizons
  \end{itemize}
\end{itemize}

Auto-promotion:

\begin{itemize}
\tightlist
\item
  requires gate pass + \texttt{TFE\_POLICY\_AUTO\_PROMOTE=true}
\item
  strict postgres mode promotes to Postgres runtime table only
\item
  non-strict can atomically replace runtime policy file
\end{itemize}

\subsection{4. Oracle Short-Cycle Gate}\label{4-oracle-short-cycle-gate}

\subsubsection{4.1 Invocation point and skip/run
policy}\label{41-invocation-point-and-skiprun-policy}

\texttt{run\_refresh\_with\_l5\_learning.py} decides if oracle
short-cycle runs:

\begin{itemize}
\tightlist
\item
  Skip rule for targeted refresh with no effective rows.
\item
  Trigger policy (\texttt{TFE\_REFRESH\_ORACLE\_TRIGGER\_POLICY}):

  \begin{itemize}
  \tightlist
  \item
    \texttt{always}
  \item
    \texttt{scheduled\_only}
  \item
    \texttt{explicit\_only}
  \item
    default \texttt{scheduled\_or\_explicit}
  \end{itemize}
\item
  Explicit override:
  \texttt{TFE\_REFRESH\_ORACLE\_ALLOW\_SHORT\_CYCLE=1}
\end{itemize}

\subsubsection{4.2 Oracle controller
behavior}\label{42-oracle-controller-behavior}

\texttt{tools/oracle\_program/oracle\_program.py\ short-cycle}:

\begin{itemize}
\tightlist
\item
  Preflight checks critical files/path alias.
\item
  Launches runner process, polls progress, writes heartbeat.
\item
  Recovery controls:

  \begin{itemize}
  \tightlist
  \item
    max runner restarts (\texttt{TFE\_ORACLE\_MAX\_RUNNER\_RESTARTS},
    default 3)
  \item
    deterministic failure signature repeat cap
    (\texttt{TFE\_ORACLE\_MAX\_DETERMINISTIC\_SIGNATURE\_REPEATS},
    default 2)
  \end{itemize}
\item
  Timeout controls:

  \begin{itemize}
  \tightlist
  \item
    cycle timeout
  \item
    no-progress timeout (effective timeout \textgreater= runner timeout
    + 120 sec)
  \end{itemize}
\end{itemize}

Output summary includes:

\begin{itemize}
\tightlist
\item
  target metric id
\item
  requested/actual additional runs
\item
  best score
\item
  target met boolean
\item
  latest epoch schema and status
\item
  session log path + state snapshot path
\end{itemize}

\subsubsection{4.3 Gate enforced in refresh
wrapper}\label{43-gate-enforced-in-refresh-wrapper}

If oracle ran, refresh wrapper hard-fails unless:

\begin{itemize}
\tightlist
\item
  \texttt{best\_score\ \textgreater{}=\ target\_return\_lift\_pct}
  (default target 4.0)
\item
  \texttt{epoch\_library\_confidence\_schema\ ==\ "v1"}
\end{itemize}

    \item
      \texttt{PSCF\_FALLBACK\_ANOMALOUS} (if anomaly fallback enabled)
    \end{itemize}
  \end{itemize}
\end{itemize}

\subsubsection{6.4 Portfolio advisor
behavior}\label{64-portfolio-advisor-behavior}

\texttt{web/src/app/api/portfolio/route.ts}:

\begin{itemize}
\tightlist
\item
  Uses runtime snapshot + quote cache + live price map.
\item
  Builds position decisions from same \texttt{decisionInfoFromRow}
  contract.
\item
  Allocator method: \texttt{PFSC\_STRUCTURAL\_ALLOCATOR\_V1}.
\item
  Action set: \texttt{BUY\_MORE}, \texttt{TRIM}, \texttt{EXIT},
  \texttt{HOLD}.
\item
  Core rules:

  \begin{itemize}
  \tightlist
  \item
    \texttt{Avoid} -\textgreater{} target 0 -\textgreater{}
    \texttt{EXIT}
  \item
    \texttt{Accumulate} score = confidence
  \item
    \texttt{Hold} score = confidence * 0.5
  \item
    fallback-unmapped hold suppresses buy-more
  \item
    trim on accumulate is suppressed
    (\texttt{ALLOW\_TRIM\_WHEN\_DECISION\_IS\_ACCUMULATE=false})
  \item
    rebalance threshold = 1.0 pct points drift
  \end{itemize}
\end{itemize}

\subsection{8. Practical Classification of Current L5
Path}\label{8-practical-classification-of-current-l5-path}

Based on current implementation boundaries:

\begin{itemize}
\tightlist
\item
  L5 is currently a cell-mapped policy layer built from serialized
  structural features and evaluated against SPY-relative outcomes.
\item
  Promotion is non-regression gated across horizons plus mapping-rate
  non-degradation.
\item
  Advisor surfaces consume runtime snapshot rows + policy key matching
  with explicit fallback contract.
\end{itemize}

Operationally this is a pragmatic, productionized policy runtime with
explicit gates and fallbacks, not an unconstrained heuristic path.
